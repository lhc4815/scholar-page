# 스콜라시프트 (Scholar Shift)

한국 교육 컨설팅 전문 웹사이트

## 설명
대학 입시 상담을 전문으로 하는 스콜라시프트 컨설팅 회사의 웹사이트입니다.

## 기능
- 9개 핵심 프로그램 갤러리 및 상세 페이지
- 전통적인 게시판 형태의 뉴스 섹션
- 상담 예약 시스템
- 반응형 디자인

## 기술 스택
- Frontend: React + TypeScript + Vite
- Backend: Express.js + Node.js
- UI: Radix UI + Tailwind CSS
- Database: PostgreSQL + Drizzle ORM

## 실행 방법
```bash
npm install
npm run dev
```

웹사이트는 http://localhost:5000 에서 확인할 수 있습니다.
